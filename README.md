# FLIGHT-MANAGEMENT

Project Description

A simple application developed to manage flights and passengers, check flight by passenger, to add a new flight, to book tickets and cancel the tickets.

Technologies Used

MySQL / Python / Interface with Python 

Features
• Add Flight and Passengers details
• View Passengers by flight records
• To add a new flight
• Booking or Cancelling of flight tickets

What I Learned

Programming logic, data handling, Database management, and project organisation.
